# 编辑器导出

高级编辑器导出显示阶段进度：排队、解码、显影或胶片处理、缩放、渲染、编码、写入或登记。进度条表示处理阶段，大图显影期间不会模拟逐像素百分比。

解码、图像处理和编码在独立工作进程运行，同一时间只允许一个导出工作进程。原生调用阻塞时，可以取消导出并终止工作进程；前端等待后台任务确认结束后恢复编辑。工作进程只写临时目录，不操作照片库和最终目标文件。

主进程在编码完成后负责原子落位和照片库登记。这一小段操作开始后不再接受取消，避免已落位文件和数据库状态不一致。取消的任务保留在任务账中，数据库沿用 `error` 终态，接口将取消原因投影为 `cancelled`，兼容现有数据库约束。

导出进度栏提供“强制退出”，确认后会终止导出工作进程并退出整个应用，不等待驱动或预览会话清理，未保存的编辑会丢失。托盘也提供明确标注丢弃未保存编辑的强制退出入口。普通关闭和托盘普通退出仍遵循既有行为。

全分辨率 RawLab 胶片导出使用 CPU 路径，避免争用交互预览的 GPU 和大图读回阻塞；交互预览继续使用既有 GPU 管线。导出工作进程在 Tauri 和单实例插件初始化之前分流，不会额外打开应用窗口。
