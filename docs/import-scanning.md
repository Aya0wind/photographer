# 导入设备扫描

导入按三个阶段运行：发现设备时只统计可导入照片数量；进入挑选页才取得文件名清单；清单完成后才读取可见文件的大小。每次打开向导或切换来源默认使用列表，缩略图由用户主动切换到网格后加载，扫描期间暂停缩略图与大小请求。原图读取、EXIF 解析与查重留在实际导入阶段。

读卡器、相机挂载磁盘和文件夹共用目录计数实现，不逐文件取得大小、修改时间，不构造完整文件条目、不排序。挑选页枚举名称也不读取这些属性；正式导入使用独立的详细枚举，保留真实属性。混合文件/文件夹选择先按所选根排除重叠，再计数，避免为统计构造完整去重集合。目标排除子树在遍历前跳过。

Windows WPD/MTP/PTP 对所有品牌尝试设备声明支持的标准计数操作。JPEG 和已验证的 Sony ARW 格式计数须能解释全部非文件夹对象；其他 RAW 格式、视频或未知对象不能可靠解释时，回退到最小名称/类型枚举。回退结果保存在当前设备源中，挑选页直接复用，不再次遍历相机；显式刷新使该缓存失效。能力缺失或查询失败不会被当成零张照片。

Sony SDK、libgphoto2 和 macOS ImageCapture 当前尚未接入导入向导的存量文件枚举，不额外启动这些控制后端来计数。macOS 挂载卷仍使用上述共用文件系统路径。

设备日志分别记录 `device count complete`、`device count fallback complete` 和 `device names complete` 的数量与耗时；WPD 日志另外记录批量属性及单对象查询次数。应以目标平台接机日志判断实际耗时，不能把本地目录测试当成 USB 相机性能数据。
