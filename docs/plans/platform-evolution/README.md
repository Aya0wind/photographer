## 已确认的前提

1. 单仓多应用：桌面、手机、Web 三种产品，各自构建发布；不按操作系统拆产品。
2. 桌面与手机本地模式为单用户；二者都能作为客户端接入服务器，服务器是协作与权限的权威。
3. Web 关注照片管理、多人协作和同步，不移植联机拍摄，不要求浏览器实时编辑引擎；保留高级配方编辑、异步预览与成片能力，详细裁剪后续讨论。
4. Rust 为主，允许 C/C++ 原生组件；Python 等用于构建、生成、管理和离线工具，不作为常规应用运行时。脚本扩展另行设计。
5. 原生多核/SIMD/GPU 友好，减少复制和读回，统一资源预算；CPU 路径可用，自动回退与强制 GPU 区分。
6. 一个 Cargo workspace，共用锁文件，仓内 path 依赖；TypeScript 组件通过公开包入口直接消费源码。
7. 按能力提取 crate，复用现有算法与业务；测试跟随职责，单测贴近实现，集成测试放在其覆盖的最小完整范围。
