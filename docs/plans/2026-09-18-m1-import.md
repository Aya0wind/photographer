# M1 设备检测 + 导入引擎 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 读卡器/WPD 相机热插拔检测→弹窗→确认→高性能流式导入（模板归档/分层查重/断点恢复/进度通知/总结日志）。

**Architecture:** `DeviceSource` trait 抽象卷设备与 WPD 相机；导入引擎 = ImportStage 中间件链 + N 并发复制流（单遍读取同时完成哈希/类型识别/写入）；journal（SQLite jobs/job_files）驱动断点恢复；领域事件总线节流推送前端。

**Tech Stack:** windows crate（WM_DEVICECHANGE / WPD COM）、rusqlite(bundled, WAL)、xxhash-rust/sha2、kamadak-exif（仅 DateTimeOriginal+相机型号）、tauri-plugin-notification。

**Spec:** `docs/specs/smart-photo-design.md` §5.1 设备、§5.2 导入引擎、§5.4 Schema、§6 性能、§7 可靠性、§8 扩展性

## Global Constraints

- 单遍读取：复制流内联哈希（xxHash64 索引 + SHA-256 主键），任何文件最多读源一次（回读校验除外，按设置）
- `.part` 临时文件 + 长度校验 + 原子 rename；journal 每文件落状态
- WPD 源并发=1，卷源并发默认 = min(4, 微基准推荐)；并发可配 1-8
- IPC 命名空间 `device.*` / `import.*`；事件 `device://arrived` 等 `xxx://yyy` 形式；节流：文件进度 ≥100ms 或 ≥20 文件合并推送
- 查重分层：同路径同名→(size+mtime)→（卷源）首尾 64KB xxh 局部→全量 (size, sha256)；命中默认跳过并记 job_files.state=skipped
- cargo fmt/clippy(-D warnings)/test 全绿；conventional commits；每个 Rust 任务 TDD

## 依赖关系与并行策略

- T1 事件总线、T2 数据库基础：无依赖，可并行

- T5 模板、T6 EXIF-lite：独立

### Task 3: 卷设备源 + 热插拔（devices/volume.rs, devices/hotplug.rs）

**Files:** Create `src-tauri/src/devices/mod.rs`（trait+注册表）、`devices/volume.rs`、`devices/hotplug.rs`；Modify `Cargo.toml`（windows crate，features Win32_UI_WindowsAndMessaging/Storage_FileSystem/Devices_DeviceNotification/System_SystemServices）

**Interfaces:**
```rust
pub enum SourceKind { Volume, Mtp }
pub struct FileEntry { pub id: String, pub rel_path: String, pub size: u64, pub mtime: DateTime<Utc> }
pub trait DeviceSource: Send + Sync {
  fn id(&self) -> String;          // 卷盘符 or WPD PnP id
  fn kind(&self) -> SourceKind;
  fn name(&self) -> String;        // 卷标 or 设备友好名
  fn list(&self) -> Result<Vec<FileEntry>>;
  fn open_head(&self, id: &str, max: u64) -> Result<Vec<u8>>;   // 前 max 字节
  fn stream(&self, id: &str) -> Result<Box<dyn Read + Send>>;
}
pub fn register_source(factory: fn() -> Result<Box<dyn DeviceSource>>);  // registry: HashMap<String, factory>
pub const MEDIA_EXTS: &[&str];   // jpg/jpeg/png/heic/avif + cr2/cr3/nef/arw/raf/dng/orf/rw2/r3d... + mp4/mov/avi/mkv/wav/mp4...
pub fn classify(name: &str, head: &[u8]) -> AssetKind;  // 扩展名 + 魔数(II*\0/MM\0*/ftyp/RIFF...) 双保险
```
- hotplug.rs：独立线程 CreateWindowExW(0,"STATIC"…-message-only 窗口) + RegisterDeviceNotification(DBT_DEVTYP_VOLUME 与 WPD 设备接口 GUID_DEV_INTERFACE_WPD)，泵 GetMessage 循环 → EventBus.publish(DeviceEvent::Arrived/Removed)；卷事件解析盘符。
- volume.rs：list = 递归遍历（忽略 System Volume Information/$RECYCLE.BIN），MEDIA_EXTS 过滤；open_head 用 FILE_FLAG_SEQUENTIAL_SCAN。

**Tests:** classify 各格式魔数矩阵（含伪装扩展名）；list 过滤与忽略目录（tempdir 造树）；rel_path 归一化（`\`→`/`）。热插拔为手动验收项（插 U 盘）。

### Task 7: 导入引擎（import/engine.rs, import/stage.rs, import/dedup.rs）

**Files:** Create `src-tauri/src/import/{mod,engine,stage,dedup}.rs`

**Interfaces:**
```rust
pub struct ImportPlan { pub source_id: String, pub target_root: PathBuf, pub dir_template: String,
  pub name_template: String, pub duplicate: DuplicatePolicy, pub skip_imported: bool, pub streams: u32 }
pub trait ImportStage: Send + Sync { fn name(&self) -> &'static str; fn run(&self, ctx: &mut FileCtx) -> Result<(), StageError>; }
pub struct FileCtx { pub entry: FileEntry, pub head: Vec<u8>, pub xxh: u64, pub sha: [u8;32],
  pub dst: PathBuf, pub meta: MetaLite, pub state: FileState, pub bytes_done: u64 }
pub struct Engine { /* Db、EventBus、源、plan、Cancellation(token)、Pause(Notify) */ }
impl Engine {
  pub fn new(db, bus, source: Box<dyn DeviceSource>, plan: ImportPlan) -> Self;
  pub fn resume(db, bus, source, job_id) -> Result<Self>;   // journal 重建：verified/skipped 跳过
  pub async fn run(self, handle: asyncio 桥) -> JobStats;   // 内部：扫描→过滤已导入→建 job→N 复制流
}
pub struct JobStats { pub total_files, done, skipped_duplicates, failed, total_bytes, done_bytes, elapsed, bytes_per_sec, failures: Vec<(String,String)> }
```
- 单文件流（阻塞线程池 rayon/线程，async 外壳只做编排）：循环读 8MB → xxh64+sha256 update → 写 .part → 首块截存 head(≤1MB) → 完成：len 校验 → fs::rename → journal verified → AssetRepo.upsert
- 查重顺序（先查后拷）：skip_imported 且 AssetRepo.find_by_size_xxh 命中 → skipped；再路径冲突 → unique_path（Rename 策略）；卷源另做首尾 64KB 局部哈希预筛（WPD 源跳过此层）
- 暂停：Pause 标志（当前文件完成后停），恢复继续；取消：同软取消；目标盘掉线 → publish Unavailable + auto-pause
- 通知：Throttle 控 FileProgress；25/50/75/100% 里程碑发系统通知（读 settings.notify_milestones）

**Tests（tempdir 模拟源目录 + 真实 Db）：** 复制完整性（字节级比对+哈希）；重复跳过计数；Rename 策略 _1 生成；中断模拟（drop engine 后 resume 续传，无重复无遗漏）；取消软停止；.part 无残留；进度事件节流后次数合理。
