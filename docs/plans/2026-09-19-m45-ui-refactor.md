# M4.5 画廊体验重构（飞牛相册对齐，用户 2026-09-19 定案）

> 参考飞牛相册真实截图 8 张提炼。两个 lane 的人脸/索引任务完成后立即执行。
> 原则：B+A 风格不变（深色沉浸 + 密度工具页），吸收飞牛的信息架构与交互模式。

## A. 全局架构（前端 lane 主刀）

### A1. 顶部全局搜索框（所有主壳页面常驻）
- 位置：TitleBar 下方或 TitleBar 内右侧区域（与菜单共存，定稿时截图评审）
- 形态：圆角大输入框，占位文案「输入一段描述搜索照片：灯火通明的街道」（语义搜索）+ 右侧过滤图标（点开条件下拉面板：类型/日期/相机，替代独立搜索页的入口职责）
- 回车 → 跳 /search?mode=semantic&q=...（语义）或 /search?filters=...（条件），搜索页仍保留完整视图
- 语义索引未就绪：输入框下方一条细提示（不阻塞输入）

### A2. 右侧任务抽屉（替代右下角浮动进度卡的唯一任务入口）
- TitleBar 右侧任务图标（带运行中任务数徽标）→ 右侧滑出抽屉（360px，surface 底）
- 内容：任务流水列表——每类任务一行（图标+名称+状态）：缩略图生成（done/total）、详细信息索引、语义索引（N/M 进度条）、导入任务、人脸识别（M4 后期）——失败行红字显示错误计数
- 每行操作：暂停/继续（索引类）；顶部「全部暂停/清除已完成」
- ImportProgressCard（右下角浮动卡）**废除**，其内容并入抽屉首行；importSessionFinished 总结弹窗保留
- 事件源：indexTaskProgress / importFileProgress / indexTaskResumed 全部汇入

### A3. 侧栏信息架构重排（飞牛式分组）
- **浏览**：图库 / 收藏（F5 前占位禁用）/ 最近添加（captured_at 30 天内）
- **组织**：相册（智能相册并入）/ 人物 / 媒体类型 / 标签（=智能分类，后续与场景标签合并）
- **工具**：重复检查（F8 占位）/ 导入 / 任务
- **系统**：设置
- 搜索不再是侧栏一级项（由全局搜索框承担）；/search 路由保留
- 媒体类型页：照片/RAW/视频 三大卡（毛玻璃封面=该类随机一张的模糊缩略图+图标+计数），点击进过滤后网格

### A4. 图库 justify 网格升级（方格 → 飞牛式）
- 数据：AssetDto 已有 width/height（EXIF 深提取存量 null——回填任务挂 index_tasks kind=exif 补齐；无尺寸的用 4:3 默认兜底）
- 行高统一 ~220px，行内按宽高比分配宽度（经典 justify 算法），虚拟化保留
- 右侧年份吸顶条（2026/2025… 竖排，滚动联动，点击跳年）

## B. 功能页升级

### B1. 智能分类标签卡片墙（替代文字列表）
- 场景标签（~40 个中文，对齐飞牛词表：夜景/天空云彩/公园/山/湖泊/海洋/海滩/森林/桥/河流/日出日落/广场/街道/花/草/烟花/猫/狗/鸟…）
- 每标签一张卡片：封面=该标签下第一张照片（后台逐个预取，限 3 并发；无图用渐变底+标签名）
- 点击 → 该标签结果网格

### B2. 相似照片页（F8 的 UI 对齐飞牛）
- 组卡：组内网格 + 「合并保留项」accent 标记（默认清晰度最高者）+ 文件名/大小/尺寸/路径
- 顶部：重新检查 / 合并全部 按钮；组按日期分组显示

### B3. 收藏与最近添加
- 收藏：rating>0 或 flagged 的资产（M5 数据就绪前空态）
- 最近添加：created_at DESC 网格

- 维护工具：重建索引（=清 thumbs+index_tasks 重跑）/ 重建语义索引

## C2. RAW 两阶段渐进显示（用户定案 2026-09-19，参考飞牛）

**两档体验**：
- **快档（现有）**：内嵌预览提取 → 秒出。飞牛同款第一阶段——相机直出 JPEG，观感可用
- **精档（新增）**：后台用 raw 解码管线（dcraw 式 demosaic 或评估现有 crate）把 RAW 全量转成正立高清 JPEG（长边 ~2048-2560，质量 85），写入 `dbDir/raw_jpg/<asset_id>.jpg`，完成后**直接替换**前端显示（thumbnailReady 类事件或轮询）——用户看到"图片突然变清晰"的飞牛同款体验

**实施要点**：
- 精档生成挂 index_tasks（kind="rawjpg"，CPU 通道全核；256MB 扫描上限的 SOI 提取保留为快档）
- 优先序：查看器打开的资产插队生成（当前查看的 RAW 立即触发精档）；后台批量其余
- `asset_thumb_get`/查看器回退链不变：精档就绪前返回内嵌预览档，就绪后返回 raw_jpg 大图
- 存储：每张 RAW 额外 ~1-2MB；与 thumbs 一样随库迁移；M8 做 LRU
- 解码选型先调研：`rawloader`（纯 Rust demosaic，之前实测无 thumbnail API 但 decode 可用）vs 捆绑 libraw（rsraw）——以"能跑通+速度"为准，demo 后定

## D. 执行序
1. A2 任务抽屉（用户痛点最直接）+ 废除浮动卡
2. A1 全局搜索框
3. A4 justify 网格 + exif 尺寸回填任务（后端配合）
4. A3 侧栏重排 + B3
5. A 媒体类型页 + B1 标签卡片墙
6. B2 相似照片页（F8 pHash 后端就绪后）
7. C 设置对齐

后端配合项：exif 尺寸回填（index kind=exif 补写 width/height）、pHash 相似分组（F8）、收藏标记列（M5）。
