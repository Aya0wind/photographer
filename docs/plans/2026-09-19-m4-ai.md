# M4 AI 索引实施计划（SigLIP2 语义 + HNSW + 人脸 + F5 场景标签）

> 依赖：M3 画廊/查看器/搜索落地后启动。设计依据 spec §5.6/§6/§10；本文拆成可派发的双 lane 任务包。
> 原则（全期强制）：成熟 crate 不重复造轮子、TDD、IPC 全 async 零阻塞、一切可配置、本地-only。

## 后端任务包（Rust lane）

### T1 基础设施
- 依赖选型：`ort`（ONNX Runtime，DirectML feature，CPU 回退）、`usearch`（HNSW）、图像解码复用 thumbs 的 turbojpeg 管线（JPEG）；RAW 内嵌预览提取用 `rawloader`（只读内嵌 JPEG，不完整解码）
- **语义模型（2026-09-19 调研定案）：SigLIP 2（siglip2-base-patch16-256，双塔 ~350MB）替代 CLIP ViT-B/32**——zero-shot/图文检索全面更优、原生多语言（中文语义直接可用，无需双语提示词对照），标准固定分辨率变体 ONNX 导出成熟（避开 NaFlex 动态分辨率变体）；向量 768 维。
- 人脸模型：SCRFD (~2.5MB) + ArcFace (~16MB)，insightface ONNX 转换版。**在线按需下载（用户定案 2026-09-19）**：安装包不含模型——首次开启对应 AI 功能时提示下载，或设置页主动下载；存 `%APPDATA%\com.smartphoto.app\models\`（应用数据根，不进库）。下载器：tauri-plugin 的 HTTP（reqwest stream）+ SHA256 校验 + 断点续传（.part + Content-Range）；模型清单（URL/SHA256/体积/版本）做成 JSON 常量便于后续换模型。IPC：`ai_models_status() -> Vec<{id,installed,bytesTotal,version}>`、`ai_model_download(id)`（进度事件 aiModelDownloadProgress{id,doneBytes,totalBytes}/aiModelDownloadFinished{id,ok,error}）、`ai_model_delete(id)`（释放磁盘）。下载中禁止启用对应功能；镜像地址可配（设置高级项，默认 HuggingFace 直连+备选 hf-mirror.com）
- IndexTask 队列统一接口（§5.6）：优先级 导入>缩略图>AI；CPU 上限（默认 50%，busy loop 让出）、仅空闲调度（ai.index_schedule）、可暂停

### T2 SigLIP2 嵌入 + HNSW
- `embed_asset(asset_id)`：缩略图 256px（SigLIP2 B/16-256 原生分辨率）→ 图像向量 768 维 FP16 → usearch 索引（dbDir/vectors.usearch，键=asset_id）+ SQLite 记录 indexed_at
- batch 32-64；DirectML 失败自动回退 CPU（日志告警 + settings.ai.use_gpu 置 false 提示）
- 增量：导入完成后按调度入队；库切换时懒加载各自 usearch 文件

### T3 语义搜索
- `search_semantic(text: String, limit) -> Vec<{assetId, score}>`：SigLIP2 文本塔编码（原生多语言，中文直搜）→ HNSW 查询
- IPC 与画廊网格组件复用（前端只需一个新搜索模式入口）

### T4 人脸（SCRFD + ArcFace + 在线聚类）
- `face_index_asset`：SCRFD 检测→裁剪→ArcFace 512 维→SQLite faces 表（asset_id/box/embedding BLOB/cluster_id nullable）
- 在线聚类：新向量与现有簇心余弦距离 > 阈值（默认 0.4，可配）→ 新簇；人数>500 时合并近簇
- `faces_clusters() -> Vec<{clusterId, count, coverAssetId}>`、`cluster_rename(cluster_id, name)`（people 命名）、`cluster_delete`（人脸数据一键清除=隐私要求，全删 faces 表+向量）
- 人脸图标/分组页数据源

### T5 F5 场景标签（零样本）
- ~20 类中英提示词（人像/风景/夜景/美食/建筑/街拍/微距/动物/花卉/海/山/雪/日落/室内/文档/截图/婚礼/运动/黑白/其他）；每资产批量算一次余弦 top1-2（>阈值 0.2）写 tags 表
- `assets_by_tag(tag)` 智能相册数据源

### 测试
模型文件不进 git；单测用随机向量桩 + 小型真模型 smoke（#[ignore] 手动跑，直连样例文件）；DirectML 不可用环境的 CPU 回退路径必须覆盖

## 前端任务包（React lane）

### T1 AI 设置页激活 + 首次引导
- 设置 AI tab 从占位转实：三开关/调度/CPU 滑条/GPU 开关（回退提示）；「人脸数据一键清除」红色确认
- 首启 AI 三选一（全开/仅语义/全关）挂在新建库配置链末尾（AI step 已有骨架，接真开关）

### T2 语义搜索 UI
- 搜索页加「语义」模式：文本框→search_semantic→结果复用画廊网格（带相似度角标）
- 中文占位提示（效果依赖模型词汇表，v1 双语提示词）

### T3 人脸分组页（people）
- 侧栏新增「人物」入口：簇网格（封面=coverAsset、计数、可命名重命名、可删）；点击进该人照片列表（复用画廊网格）

### T4 智能相册（F5）
- 侧栏「智能相册」：场景标签列表（计数）→ 点击进对应照片网格

### T5 索引状态可视化
- 设置/菜单：AI 索引进度（已索引/总数、暂停/恢复按钮、GPU/CPU 当前模式）——复用 ImportProgressCard 模式

## 验收
- 全部本地推理（无网络调用）；20 万库 HNSW 查询 <10ms（benchmark 用例）
- GPU 不可用自动回退不崩；人脸清除彻底；中文 UI 全覆盖
- cargo + vitest 全绿；真机（你的 6600XT/DirectML）跑通语义搜索与人脸聚类
