# M5-M8 功能波次计划（选片/评分XMP/LR导出/监视文件夹/那年今天/去重/器材统计/打磨）

> M4（AI）之后按波次推进；每波双 lane 并行、集成提交打 tag。依据 spec §2/§5.2/§5.8/§9。

## M4.5：画廊体验波（用户 6 条反馈 + RAW 预览，2026-09-19 定案）
- RAW 缩略图：rawloader 提取内嵌 JPEG 预览喂 turbojpeg 管线（缓存规则不变）；展示时右上角 RAW 水印角标（合并展示卡显示 RAW+JPG）——提取要真实画面，水印保辨识
- RAW+JPG 合并展示（设置开关默认开，pair_asset_id 配对列，优先显示 JPG、点击开 JPG）
- 搜索页日期范围选择器（原生 date input+快捷段）；相机多选勾选（camera_list + cameras 数组化）
- 查看器旋转（90° 步进+R 键）；画廊/搜索三档展示尺寸（120/200/280 右上角切换）；画廊内容区居中修复

## M5：评分 + XMP 边车 + LR 互通（§5.8）
后端：
- 评分/旗标模型：assets 表 rating(0-5)/flag/rejected + `asset_rate(id, rating)` IPC
- XMP 边车写入：`xmp_sidecar_write`（对收纳区资产在同目录写 .xmp；外部/只读路径跳过并计数）——选型 rustic-xmp 或最小手写 XMP 模板（先调研成熟 crate，没有再手写模板，FLMWO 风格字段：rating/label）
- LR watched-folder 导出：收藏/旗标变更时镜像到用户指定目录（collections 表 + 导出任务，notify 文件监听复用 hotplug 模式）
- F4 监视文件夹（提前到本波顺手做，§5.2 已定：notify 监听、大小稳定 1.5s 触发、移动入库）
前端：查看器评分条（0-5 星+旗标）、设置「文件写入」tab 激活（XMP 开关/LR 目录选择）、变更即写提示

## M6：F3 AI 选片
后端：连拍分组（同相机+拍摄时间 Δ≤2s+参数近似）→ 每组打分：清晰度（拉普拉斯方差 SIMD）+曝光异常+（若 M4 人脸开）眨眼近似（闭眼=人脸得分低）→ 最佳帧标记 best_shot
前端：连拍组折叠视图（画廊分组头部「连拍 N 张」展开）；「仅看最佳帧」开关；组内对比视图（横向大图滚动+得分角标）

## M7：F6 那年今天 + F8 pHash 去重 + F9 器材统计
- F6：`on_this_day() -> Vec<AssetDto>`（历年同月日，含 N 年前角标）；侧栏入口+首页卡片
- F8：库内 pHash（dct 8x8）全库扫描后台任务（IndexTask 队列低优先级）+ `duplicates_list() -> Vec<组>`；画廊「查重」页：组内对比、一键保留最优（清晰度/分辨率）/批量删除（进回收站语义 v1=直接删+日志）
