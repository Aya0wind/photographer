# PhotoCraft 编辑器移植计划

状态：分阶段实施；阶段 1 已实现；阶段 2 已接入新基础编辑路径，阶段 3 LUT 已可用，余项持续推进。日期：2026-10-10。

## 目标与边界

PhotoCraft 负责图像处理算法、文档与图层模型、蒙版、调整图层、LUT 解析及应用、裁剪与变换和支持格式的编解码。本项目继续负责相册/数据库、照片来源与文件归属、任务、元数据、导出落位、用户界面和设备连接。复用上游模块与命令接口，不复制一份算法，也不直接搬入整个 egui 界面。

编辑预览使用固定分辨率的本地代理及 GPU 常驻纹理；交互时更新参数，不能反复解码 RAW、编码 JPEG 或切换图像分辨率。导出读取原片，并验证色彩与参数顺序。旧配方不能在没有迁移规则和对照验证时悄悄改变效果。

当前上游固定版本：`storytold/photocraft`，`3955bf4f1911a69ea08947634b3e2b459feece2f`。升级须记录差异，不能用追随 main 替代可复现构建。

## 当前实现审计

| 功能 | 当前情况 | 移植方向 |
| --- | --- | --- |
| 高级编辑调色 | 已接入基础亮度/对比度、饱和度、自然饱和度、曲线、色阶、HSL、颜色平衡、黑白及可选颜色；预览使用缓存调整图层 | 继续补空间/邻域处理与其他调色功能，共用参数映射、顺序和持久化 |
| GPU 预览 | Windows 原生画布；初始 1×1 表面漏配置问题已修复并复现验证 | 扩展裁剪后、旋转后的调色预览；补 macOS GPU 接入与真实窗口验证 |
| 旧基础编辑器 | 仍有 Konva 调整/几何预览和旧 `edit/render.rs` 导出路径 | 逐项切换到统一 PhotoCraft 会话，完成后删除旧算法分支 |
| 裁剪与旋转 | 高级编辑导出已调用 `image.crop` / `image.imageRotation.*`；交互仍用 Konva 操作框 | 引入自由角度、翻转、比例与尺寸；控件可以保留，计算由上游承担 |
| LUT | 显示 ICC LUT 与用户 ColorLookup 分离；已接入应用及资源管理 | 用 `colorLookup` 调整图层；显示 ICC LUT 与创意 LUT 分开管理 |
| 蒙版 | 画笔/线性/径向渐变、管理、覆盖显示及局部调色 UI 已接入，配方共用 SQLite | 继续原生区域操作、跨平台和真实 RAW 验收 |
| 文件 | PhotoCraft io/codecs/source 已接入高级编辑；旧路径和格式处理仍存在 | 统一支持格式探测、解码、色彩、导出；照片归属和入册仍走本项目 |
| RAW | PhotoCraft 能解码当前 Sony RAW，但缺少相机色彩标定时使用替代矩阵 | 不让升级预览自动触发 RAW 显影；独立评估有机型标定的 RAW 输入适配器 |
| 撤销与项目保存 | 前端配方历史 + 后端持久化；原生会话用于临时渲染 | 建立一种用户编辑真值，避免前后端双重历史和重复保存 |

2. 统一 Recipe → PhotoCraft 文档的适配，补配方版本与旧项目转换规则；保留原文件与项目中的既有行为直到对应功能替换验证完成。
3. 把基础亮度、对比度、饱和度与现有滤镜迁到相同调整图层；切换普通预览、GPU 预览和导出都走同一映射。
4. 对接原生 Session 的命令与撤销语义，明确哪些状态是临时预览，哪些是已提交编辑。
5. 验收连续拖动、撤销重做、关闭取消、重新打开、批量导出、RAW+JPG 版本切换；完成项删除旧算法实现。

## 阶段 3：LUT 应用与管理

1. 核对上游支持的 LUT 文件格式及参数限制，优先 `.cube`；复用上游解析器和 `Adjustment::ColorLookup`，不自行重写插值。
2. 提供导入、列表、名称、应用、强度、移除与错误提示；资源按内容哈希复制到应用资源目录，项目持久化引用 ID。
3. 预览中保持 LUT 的纹理/图层 ID 稳定，只更新参数；导出复用相同 LUT 与色彩顺序。
4. 定义移除正在被项目使用的 LUT 的行为，避免项目重开后失效；确定打包/迁移项目所需资源。
5. 验收标准与非标准尺寸 LUT、无效/过大文件、强度 0/100%、GPU 与导出一致性。

## 阶段 4：裁剪、几何变换与显示

1. 统一 90 度旋转、水平/垂直翻转、自由角度、比例与尺寸裁剪，复用上游几何命令。
2. 操作框和拖拽手势只提供坐标；像素变换不再使用旧图像处理实现。
3. GPU 中处理可实时显示的视图变换，并保持固定原生窗口边界；裁剪后调色不能退回等待编码的模式。
4. 验收旋转前后坐标、画笔/文字与蒙版变换、原始尺寸到代理尺寸映射、窗口缩放与全屏。

## 阶段 5：蒙版与局部调色

1. 建立蒙版对象和作用于蒙版的调整图层；先接画笔、线性/径向渐变、反转、启用/禁用、羽化，再评估更复杂选择功能。
2. 蒙版使用 PhotoCraft LayerMask/selection/paint 实现，不能把灰度蒙版误当作照片图层。
3. 矢量/参数化坐标以原图归一化坐标保存；代理和导出按对应分辨率生成蒙版。
4. 实现蒙版预览、选择、命名、复制、删除和局部调整；撤销重做与项目保存共用阶段 2 的真值。
