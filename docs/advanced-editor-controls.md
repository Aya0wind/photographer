# 高级编辑器操作

调色工具集中提供影调、色彩、曲线、HSL、效果、细节、镜头与透视、胶片和调色方案。点击分组标题展开或收起。镜头校正不再占用独立工具页。

## 参数调整

- 拖动滑条实时预览；双击滑条或点击右侧复位按钮恢复默认值。
- 数字框可直接输入，Enter 确认、Escape 取消。
- 方向键按常规步长调整，Shift 使用十倍步长，Alt 使用十分之一步长。按住 Alt 拖动也可以精调。
- 同一次拖动或连续按键作为一次撤销操作。
- 同时包含正负值的滑条把零点放在中间。曝光仍为 −5 至 +7 EV，对比度仍为 −50 至 +100；居中只改变滑条显示比例。

## 直方图与曲线

直方图叠加显示 RGB 分布。显示时使用五点加权平滑和保形三次曲线，减少锯齿与折角；不修改原始统计值、照片处理或导出结果。曲线不会超出相邻显示值。

在直方图对应亮度区域横向拖动，可调整黑场、阴影、曝光、高光、白场；一次拖动对应一次撤销。

色调曲线支持点曲线和参数曲线。点曲线可添加、拖动和删除控制点，也可以输入坐标或使用取色工具。曲线后的直方图采用相同的平滑显示。

## 镜头与透视

展开调色中的“镜头与透视”后，可启用匹配的镜头配置。配置搜索和手动选择位于“镜头配置文件”中。只有镜头配置具有当前焦距校准数据的项目可用。

启用手动校正后显示畸变、色差、暗角、透视与缩放参数。手动校正在配置校正后叠加。“引导式透视”提供垂直、水平参考线；参考网格可单独开关，默认关闭。修改几何后应检查局部蒙版的位置。

RAW 配置变更时会重新准备预览。编辑窗口使用缓存预览，原尺寸细节检查可查看源文件细节；正式导出仍按原图处理。

## 侧栏与方案

顶部按钮控制左右侧栏；“更多操作”中可调整侧栏宽度、启用溢出提示、打开参考对比和细节检查。较窄窗口自动收起部分按钮文字，按钮名称保留在悬停提示和辅助功能标签中。

左侧栏包含基础风格、历史和版本；基础风格说明放在悬停提示中。胶片模拟和调色方案按需展开，强度与启停分别控制。底部胶片条可评分、标记、选择同步目标，并同步指定调整组。
