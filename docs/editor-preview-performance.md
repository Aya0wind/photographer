# 编辑器预览性能

## 缩放与布局

画布关闭浏览器自动滚动锚定，缩放定位在绘制前完成。定位使用照片内的归一化中心点，计入适应窗口时的自动外边距、滚动条和视口变化。缩小时浏览器可能先把滚动位置夹到新边界，因此必须保留缩放前的滚动位置，不能在更新布局后重新读取旧值。

滚轮输入按距离与单位换算缩放倍率，并合并到每个动画帧提交一次。触摸板的小幅输入不会每次都触发固定的 10% 缩放。

## 预览优先

拖动滑条、蒙版或目标调整时，暂停新的直方图和悬停取色请求，保留上次显示的直方图。交互结束后按最新参数恢复统计；已经在处理的主预览帧继续显示，随后跟进最新参数。

直方图使用独立缓存的 512 像素代理及渲染器，避免反复建立完整 RAW 色彩处理链或占用交互渲染器锁。直方图是代理图的分布统计，不是原图精确像素计数。照片预览和正式导出的分辨率保持原有规则。

RAW 源准备完成后最多追赶一次当前参数就发布，不再等待所有滑块都停止变化。后续预览队列负责继续跟进。导出尺寸和质量变化不使原生画布的图像缓存失效。

## 色彩处理

基础风格曲线按风格缓存，像素分块在独立、最多四线程的池中处理。每个像素的运算顺序不变；回归测试逐通道比较并行和串行结果，要求完全一致。

本地 Windows 基准使用 1600 × 1067 合成像素、同一开发构建配置：基础风格处理由约 142 ms/帧降至 43 ms/帧。统计图像生成由约 169 ms 降至首次约 73 ms，缓存命中约 4 ms。这些是单阶段基准，不代表包含 RAW 解码、GPU 提交和屏幕显示的整体帧率。

验证命令：

```text
cargo test --manifest-path src-tauri/Cargo.toml --lib profile_preview_timing -- --ignored --nocapture
cargo test --manifest-path src-tauri/Cargo.toml --lib statistics_preview_timing -- --ignored --nocapture
```
